# 阶段 5D：品规删除与表格对齐实施计划

> **执行方式：** 当前会话使用测试驱动开发逐项实施；不提交或推送 Git。

**目标：** 将品规数量统计改为严格对齐、字号清晰的标准表格，并提供保留流水证据的单行删除功能。

**架构：** 删除复用现有 `scan_events` 与 `scan_session_items`。后端在一个 MySQL 事务内校验权限、锁定批次和汇总行、追加负向 `ADJUST` 事件并删除实时汇总；前端通过带 `request_id` 的 API 请求更新权威扫描状态。页面使用原生 `<table>` 保证表头与内容共享列宽。

**技术栈：** FastAPI、Pydantic、SQLAlchemy 2.x、MySQL 8、Vue 3、TypeScript、Vitest、Playwright。
