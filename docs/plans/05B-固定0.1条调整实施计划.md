# 阶段 5B：固定 0.1 条调整实现计划

> **面向 AI 代理的工作者：** 使用 `executing-plans` 在当前会话逐任务实现。所有行为变更遵循 TDD；根据项目约定，不创建 worktree、不 commit、不 push。

**目标：** 将人工数量调整的最小单位从 1 条改为固定 0.1 条，并确保扫码业务正常返回后输入框立即清空、重新聚焦。

**架构：** 不修改数据库结构，继续使用整数 `manual_delta_sticks` 和 `total_sticks`。API 使用十进制定点数接收条数，服务层把 0.1 条换算为当前品规每条支数的十分之一；前端只允许一位小数并以 0.1 为按钮步长。

**技术栈：** Python 3.12、Decimal、FastAPI、Pydantic、SQLAlchemy、MySQL、Vue 3、TypeScript、Vitest、pytest、Playwright。
