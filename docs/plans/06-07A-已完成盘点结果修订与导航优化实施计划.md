# 已完成盘点结果修订与导航优化实施计划

> **面向 AI 代理的工作者：** 必需技能：使用 `executing-plans` 按任务实施本计划。每个任务使用复选框跟踪进度，在测试失败与通过后记录实际输出。项目约定禁止自行 `git commit` 或 `git push`，因此各任务以 Git diff 检查点结束，等待用户统一确认。

**目标：** 增加“盘点作业 / 盘点结果”双入口，修复管理员页面侧栏缺项，并让权限范围内人员在禁止扫码的前提下修订已完成批次的品规、数量和来源地。

**架构：** `scan_sessions.status` 继续只使用 `DRAFT` 和 `COMPLETED`。进行中流程复用现有扫码服务；已完成结果修订使用独立服务，在事务和行锁内同时维护 `scan_session_items`、`scan_events` 与 `scan_item_source_allocations`。前端抽出共用侧栏，列表和工作台根据路由及批次状态切换“作业模式”和“结果模式”。

**技术栈：** Python 3.12、FastAPI、Pydantic、SQLAlchemy 2.x、MySQL 8、Vue 3、TypeScript、Vite、Vitest、Playwright、OpenPyXL。

```python
def list_active_product_options(
    session: Session,
    query: str,
    page: int,
    page_size: int,
) -> tuple[list[CigaretteProduct], int]:
    normalized = query.strip()
    if not normalized:
        return [], 0
    pattern = f"%{normalized}%"
    conditions = (
        CigaretteProduct.is_active.is_(True),
        or_(
            CigaretteProduct.standard_name.like(pattern),
            CigaretteProduct.carton_code.like(pattern),
        ),
    )
    total = session.scalar(select(func.count(CigaretteProduct.id)).where(*conditions)) or 0
    items = list(session.scalars(
        select(CigaretteProduct)
        .where(
            *conditions,
        )
        .order_by(CigaretteProduct.standard_name, CigaretteProduct.id)
        .offset((page - 1) * page_size)
        .limit(page_size)
    ))
    return items, int(total)
```

API 对纯数字查询仍使用尾部模糊匹配，因此输入 6 位后缀能命中；响应 schema 只暴露批准字段。

```python
def locked_completed_session(session: Session, current_user: AuthUser, session_id: int) -> ScanSession:
    if current_user.role == Role.VIEWER:
        raise ScanSessionForbiddenError("当前账号不能修订盘点结果")
    conditions = [ScanSession.id == session_id]
    scope = data_scope_filter(current_user)
    if scope is not None:
        conditions.append(scope)
    batch = session.scalar(select(ScanSession).where(*conditions).with_for_update())
    if batch is None:
        raise ScanSessionNotFoundError("盘点结果不存在")
    if batch.status != "COMPLETED":
        raise ResultSessionNotCompletedError("只能修订已完成的盘点结果")
    return batch
```

- [ ] **步骤 6：实现手工加入和替换数量**

```python
target_tenths = int(quantity_cartons * 10)
sticks_per_tenth = int(snapshot["sticks_per_carton"]) // 10
target_sticks = target_tenths * sticks_per_tenth
scanned_sticks = item.carton_count * int(snapshot["sticks_per_carton"]) + (
```

首次加入创建 `ScanSessionItem`，其扫码计数均为 0，`manual_delta_sticks` 和 `total_sticks` 等于加入支数；已有品规则把本次加入数量累加到当前总量。替换接口直接使用目标数量。

每次操作追加 `ADJUST` 事件。系统原因包含目标数量和规范化请求摘要：

```python
fingerprint = sha256(canonical_payload.encode("utf-8")).hexdigest()
reason = f"已完成结果修订：设为 {quantity_cartons} 条；请求摘要：{fingerprint}"
```

重放时同时校验批次、品规、事件类型和摘要，避免相同 `request_id` 被不同来源数据误复用。

- [ ] **步骤 7：在同一事务保存数量、事件和来源**
