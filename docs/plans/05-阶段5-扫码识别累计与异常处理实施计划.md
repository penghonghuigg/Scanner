# 阶段 5：扫码识别、累计与异常处理实现计划

**实施状态：已完成。** 本计划按 TDD 执行；数据库显式建表、MySQL 重连持久化、真实 API/前端闭环和回归验证均已完成，Docker Compose 配置检查受当前终端缺少 `docker` 命令限制。

> **面向 AI 代理的工作者：** 必需子技能：使用 `executing-plans` 在当前会话逐任务实施；每个功能遵循 TDD 红—绿—重构。步骤使用复选框跟踪。用户要求不提交或推送 Git，因此每个任务使用 Git 状态检查点代替 commit。

**目标：** 交付具备 MySQL 持久化、幂等和并发保护的连续扫码、自动累计、异常记录和歧义解决闭环。

**架构：** 新增 `scan_events` 只追加流水和 `scan_session_items` 权威汇总表；同一批次写操作通过批次行锁串行化，事件唯一请求号和歧义来源唯一约束提供最终保护。FastAPI 返回完整扫码状态，Vue 只渲染后端权威结果。

**技术栈：** MySQL 8.x、SQLAlchemy 2.x、FastAPI、Pydantic、Vue 3、TypeScript、Vitest、pytest、Playwright。
