# 阶段 5C：平铺品规数量表实现计划

> **面向 AI 代理的工作者：** 使用 `executing-plans` 在当前会话逐任务执行；行为变更遵循 TDD，不创建 worktree、不 commit、不 push。

**目标：** 将扫码工作台的分组版本表改为 11 列平铺品规表，同时保留现有 0.1 条调整、权限和金额计算。

**架构：** `ProductQuantityTable` 直接接收 `ScanSessionItem[]`，每个汇总项渲染一行。所有数量、价格和调整请求继续绑定当前行 `product_id`，不改变后端契约。

**技术栈：** Vue 3、TypeScript、Vitest、ESLint、Vite、Playwright。
