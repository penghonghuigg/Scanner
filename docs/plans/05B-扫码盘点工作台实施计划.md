# 阶段 5B：扫码盘点工作台实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `executing-plans` 在当前会话逐任务实现此计划。步骤使用复选框（`- [ ]`）跟踪进度。所有行为变更遵循 TDD 红—绿—重构。根据本项目约定，执行期间不创建 worktree、不 commit、不 push，使用测试结果和 Git diff 作为检查点。

**目标：** 将现有扫码页升级为可持续盘点的工作台，提供准确统计、最近识别、同名版本分组、固定 0.1 条人工调整和每页 10 条的流水分页。

> **2026-09-01 修订：** 用户批准人工调整最小单位固定为 0.1 条。本文早期任务中出现的整数调整示例统一由 `docs/plans/05B-固定0.1条调整实施计划.md` 覆盖；扫码正常返回后必须先清空并重新聚焦，再刷新流水。

**架构：** 继续复用 `scan_events` 与 `scan_session_items`，不执行 DDL。后端服务层负责调整事务、行锁、幂等、分页和派生状态；FastAPI 暴露明确契约；Vue 工作台通过小型展示组件呈现后端权威数据，金额与分组只做无副作用的展示计算。

**技术栈：** Python 3.12、FastAPI、Pydantic、SQLAlchemy 2.x、MySQL 8.x、Vue 3、TypeScript、Vitest、pytest、Playwright。
